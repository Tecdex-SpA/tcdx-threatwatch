# VULNERA by TECDEX — Landing page

Landing comercial SaaS B2B para VULNERA by TECDEX.

## Ejecutar localmente

```bash
npm install
npm run dev
```

Abrir:

```text
http://localhost:3000
```

## Build

```bash
npm run build
npm start
```

## Despliegue sugerido

- Vercel con Next.js App Router.
- Landing estática.
- Formulario conectado inicialmente a endpoint seguro, CRM o email controlado.
- No solicitar contraseñas, tokens, credenciales ni secretos.
- CTA orientado a demo comercial controlada, no a ejecución inmediata de scans.

## Notas legales

La landing incluye el texto obligatorio de transparencia y evita promesas absolutas de seguridad, cumplimiento automático o reemplazo de pentesters humanos.
